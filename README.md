# JavaScript Mini Project Collection 

A collection of mini-projects built using **HTML, CSS, and JavaScript** to practise JavaScript concepts and improve frontend development skills.

This repository contains interactive web applications and small projects that demonstrate JavaScript fundamentals, DOM manipulation, event handling, and browser functionality.

## 📂 Projects

| # | Project | Description |
| 1 | Add to Cart Application | A simple shopping cart application. |
| 2 | Addition Game | An interactive game to practise addition. |
| 3 | Button Maker | Create and customize buttons. |
| 4 | Guess Game | A number-guessing game. |
| 5 | Mark Your Skill | An interactive skill-related application. |
| 6 | Random Color Generator | Generate random colors dynamically. |
| 7 | Tab Changer | Switch between different tabs. |
| 8 | Cat Light | An interactive light-control project. |
| 9 | Click Counter using Local Storage | Track click counts and store them in the browser. |
| 10 | Color Picker | Select and explore different colors. |
| 11 | Counter Application | Increment, decrement, and manage a counter. |


##  Technologies Used

- HTML5 – Structure of web pages.
- CSS3 – Styling and layouts.
- JavaScript – Interactivity and functionality.

##  Concepts Practised

- JavaScript Fundamentals
- DOM Manipulation
- Event Handling
- Functions and Conditional Statements
- Browser Local Storage
- Dynamic UI Updates
- User Interaction

##  Getting Started

Follow these steps to run the projects locally.

**1. Clone the repository**

```bash
git clone https://github.com/varuna-code7/Javascript-miniproject-collection.git
```

**2. Navigate to the project directory**

```bash
cd Javascript-miniproject-collection
```

**3. Open any project folder**

Choose the project you want to explore.

**4. Run the application**

Open its `index.html` file in your browser.

You can also use the Live Server extension in Visual Studio Code.
